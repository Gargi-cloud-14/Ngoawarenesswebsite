# 🌍 InAmigos Foundation Awareness Website

A modern and responsive NGO awareness website created to showcase the mission, projects, impact, and initiatives of **InAmigos Foundation**.

This project was developed using **HTML, CSS, JavaScript, React, and TypeScript** with a clean and visually engaging user interface to spread awareness and encourage community participation.

---

# ✨ Features

* 🎯 Modern NGO awareness landing page
* 🎞️ Fullscreen hero image slider
* 📖 About & Mission sections
* 🚀 Flagship projects showcase
* 📊 Real impact statistics
* ❤️ Donation call-to-action section
* 🖼️ Responsive image gallery
* 🤝 Volunteer engagement section
* 🌐 Social media & official website links
* 📱 Fully responsive design

This awareness platform is integrated with the official website of InAmigos Foundation to provide users with direct access to authentic information, campaigns, and support initiatives.

🌐 Official Website:
https://inamigosfoundation.org.in/

The website includes dedicated call-to-action sections such as:

❤️ Donate Now
🤝 Become a Volunteer
🌍 Explore NGO Initiatives
📢 Follow Social Campaigns

These sections redirect users to the official InAmigos Foundation platform, allowing visitors to securely contribute, volunteer, and learn more about the organization’s ongoing social impact projects and community-driven initiatives.

This integration ensures that users can seamlessly transition from awareness to real-world participation and support.
